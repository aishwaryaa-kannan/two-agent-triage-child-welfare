# Two-agent triage for flagging uncertain predictions

Code for "A Two-Agent Triage Framework for Flagging Uncertain Predictions in Child Welfare Case Prioritization" (NeurIPS 2026 NewInML workshop). All data is synthetic, generated by `triage_lib.py`. No real case data is used.

## Setup
Python 3.13, scikit-learn 1.9.1, numpy 2.5.3, pandas 3.0.5, matplotlib.

    pip install scikit-learn numpy pandas matplotlib

## Run
    python triage_eval.py       # seed-42 reproduction and risk-coverage figure
    python triage_protocol.py   # validation-selected results (Table 1)
    python triage_ablation.py   # signal ablation (Table 2)

Results are written to CSV files in the same folder. Exact numbers can shift slightly across library versions.
